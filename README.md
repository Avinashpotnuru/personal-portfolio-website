# Personal Portfolio

A [Next.js](https://nextjs.org/) portfolio built with React, Tailwind CSS, and Framer Motion.

## Getting Started

Install dependencies and run the development server with pnpm:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Scripts

| Script | Description |
| ------ | ----------- |
| `pnpm dev` | Start the development server |
| `pnpm build` | Build the application for production |
| `pnpm start` | Start the production server |
| `pnpm lint` | Run ESLint |
| `pnpm analyze` | Build with bundle analyzer (set `ANALYZE=true`) |
